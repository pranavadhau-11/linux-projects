Linux User Management Automation

Project Overview

A Bash Shell Scripting project developed on Red Hat Enterprise Linux 10 to automate Linux user and group management tasks.

Features

- Automated user creation
- User existence verification
- Group creation
- User-to-group assignment
- Display Linux users
- User deletion
- Activity logging

Technologies Used

- Red Hat Enterprise Linux 10
- Bash Shell Scripting
- Linux User Management Commands
- Git & GitHub

Commands Used

- "useradd"
- "usermod"
- "userdel"
- "groupadd"
- "id"
- "getent"
- "cut"

How to Run

git clone YOUR_GITHUB_REPOSITORY_URL
cd user-management-automation
chmod +x user-management.sh
sudo ./user-management.sh

Learning Outcomes

- Linux user and group administration
- Bash automation
- Conditional statements and loops
- Case statements
- Logging and error handling
- Linux system administration
