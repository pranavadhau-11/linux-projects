PROJECT PREREQUISITES

Enterprise Linux Storage Management

1. Hardware Requirements

- Laptop or Desktop Computer
- Minimum 8 GB RAM recommended
- Sufficient free disk space
- Additional virtual hard disk for storage practicals

2. Software Requirements

Software| Purpose
VMware Workstation| Virtualization
RHEL 10| Linux Operating System
Bash Shell| Shell Scripting
Vim Editor| Script and file editing
Git| Version Control
GitHub| Project Hosting

3. Linux Knowledge Requirements

Basic knowledge of:

- Linux commands
- Linux filesystem hierarchy
- Disk and partition concepts
- Filesystem types
- Mounting and unmounting
- User permissions
- Root and sudo access
- Basic Bash scripting

4. Required Storage Commands

- lsblk
- fdisk
- blkid
- df
- du
- mount
- umount
- mkfs
- mkswap
- swapon
- pvcreate
- vgcreate
- lvcreate

5. Safety Requirements

- Use a dedicated virtual disk for practical operations.
- Verify disk names before making changes.
- Take backups before modifying storage.
- Verify filesystem and mount configurations.
- Avoid modifying the operating system disk.

6. Project Environment

Operating System: RHEL 10

Virtualization Platform: VMware Workstation

Project Type: Linux Storage Administration

Automation: Bash Shell Scripting
