PROJECT OBJECTIVES

Enterprise Linux Storage Management

1. Main Objective

To understand and implement Linux Storage Management using Red Hat Enterprise Linux 10 in a virtualized environment.

2. Specific Objectives

1. Understand Linux storage architecture.
2. Identify and inspect available storage devices.
3. Create, modify and manage disk partitions.
4. Create and manage Linux filesystems.
5. Perform filesystem mounting and unmounting.
6. Configure permanent mounts using /etc/fstab.
7. Create and manage swap space.
8. Understand and implement Logical Volume Management (LVM).
9. Extend logical volumes and filesystems.
10. Monitor disk utilization using Bash shell scripting.
11. Automate storage monitoring tasks.
12. Understand backup and recovery procedures.
13. Troubleshoot common Linux storage issues.

3. Automation Objectives

- Develop Bash scripts for disk monitoring.
- Display disk utilization percentage.
- Identify storage usage status.
- Reduce manual monitoring tasks.

4. Expected Outcomes

After completing this project, the learner will be able to:

- Perform basic Linux storage administration.
- Manage disks, partitions and filesystems.
- Configure and manage LVM.
- Monitor storage utilization.
- Use Bash scripting for basic automation.
- Perform basic storage troubleshooting.

5. Career Relevance

This project helps develop practical skills relevant to:

- Linux System Administrator
- Junior Cloud Engineer
- Technical Support Engineer
- Infrastructure Support Engineer
